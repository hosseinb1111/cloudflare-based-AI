# 🚀 AI Chat

A modern AI chat application built with **Cloudflare Workers**, featuring **real-time streaming**, **long-term memory**, **image support**, **conversation management**, and a beautiful responsive interface.

Designed to be fast, lightweight, and scalable while running entirely on Cloudflare's edge.

---

## ✨ Features

### 💬 AI Chat

* Real-time streaming responses
* Markdown rendering
* Syntax-highlighted code blocks
* Copy code with one click
* Stop & Resume generation
* Conversation history
* Automatic conversation titles

### 🧠 Long-Term Memory

* Persistent user memory
* Automatic memory extraction
* Manual memory management
* Memory injection into future conversations
* Edit & delete memories
* Per-user memory storage

### 🌐 Web Search

* Live web search integration
* Search toggle
* Uses fresh online information when enabled
* Falls back gracefully if search is unavailable

### 🖼️ Image Support

* Upload images
* Drag & Drop support
* Image previews
* Multiple image uploads

### 📁 Conversation Management

* Create unlimited conversations
* Rename conversations
* Delete conversations
* Search conversations
* Export conversations

Supported export formats:

* Markdown
* HTML
* TXT
* JSON

### 🎨 User Experience

* Beautiful modern UI
* Dark Mode
* Light Mode
* Responsive Design
* Desktop & Mobile support
* Smooth animations
* Multi-language support (English & Persian)

### 🔒 Security

* JWT Authentication
* Per-user data isolation
* Cloudflare KV storage
* Rate limiting
